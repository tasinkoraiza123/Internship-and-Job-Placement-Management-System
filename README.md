# Internship & Job Placement Management System

A web-based application designed to manage student internships, job applications, and placement records efficiently. The system connects students and companies while helping manage recruitment and eligibility requirements.

## Features

- **Student & Company Registration:** Register students and companies in the system.
- **Internship & Job Posting:** Allow companies to publish internship and job opportunities.
- **Application Tracking:** Manage and track student applications.
- **Eligibility Checking:** Determine student eligibility based on CGPA and department.

## Technologies Used

- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript
- **Local Development Environment:** XAMPP

## How to Run

1. Install XAMPP
2. Start Apache & MySQL
3. Import the database
4. Run the project on localhost

## Project Purpose

The goal of this project is to simplify internship and job placement management by organizing student information, company opportunities, applications, and eligibility requirements in one centralized system.
